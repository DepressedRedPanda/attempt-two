# HEAVY METTLE — instructions for Claude Code
This repository belongs to a player building a Blueprint-first, editable Unreal Engine third-person space western. **Provisional engine baseline: UE 5.5.4, plain Third Person Blueprint template** (see docs/DECISIONS.md, 2026-10-18); 5.8.3/Combat-variant text below is historical until revisited. Work only toward the first playable game; one small testable step per PR, explained for a complete beginner, with decisions logged in docs/DECISIONS.md. Do not bring back Hollowreach/VeilOfAsh C++ modules. The current GitHub text cannot create binary .uassets, so separate researched/planned features from tested-in-Unreal features.
First task when connected to a real editor: follow docs/START_HERE_UE55.md (Third Person Blueprint template on 5.5.4), run Scripts/build_dustfall.py, test Play in Editor and commit generated .umap/.uasset files under Git LFS. Implement short-distance lock-on (<=350 cm), free-aim handgun, weapon body sockets, simple melee light/heavy combo and guard/parry; keep each change individually playable. Maintain a 'WORKS IN PIE' checklist in the README and never declare an untested feature done. Coordinate via Issues/PRs and leave only Blueprint assets/runtime logic in Content (editor Python tools are acceptable; no gameplay C++). Review data/balance.json and docs/CREATIVE_DIRECTION.md.


## Owned library integration
Read docs/OWNED_LIBRARY_ASSET_PLAN.md before adding external assets. The user screenshot shows assets in Epic Launcher but the files were not imported into the public repo. Prioritize Free Animation Library (mantles/vault), FREE Sword + Animation (sword mesh, not sword combo system), Easy Crosshair (textures only), Free Firearm Sounds, Ultra Components inventory/shooter (isolated compatibility test). The deliberate 5.5 path was chosen on 2026-10-18 (docs/DECISIONS.md): confirm each Fab asset lists 5.5 support before importing. Never upload third-party binaries until licensing is checked; run Scripts/audit_imported_assets.py locally to report candidates, then run PIE and report logs.


## Platform mandate
Lead design platform is PS5, build/test on Windows first with controller input via Enhanced Input. Read docs/START_HERE_PS5_MULTIPLATFORM.md for beginner setup, mapping plan, official Sony/Epic developer access and performance/UI guidance. Avoid hard-coded Windows paths and PlayStation-specific platform APIs in runtime game Blueprints. Official console SDK integrations require a separately approved source-built Unreal Engine and must stay outside this public repo; do not claim a retail PS5 can run our Windows .exe.
